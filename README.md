Log files for competition and selected practices

Structure is:

competition
  competition name ("ILCH" for example)
    match ID ("ILCH_q16" for qualification match #16 - other prefixes will be "P" for practice and "E" for the finals)
      individual logs - from robot and DS
practice
  practice tag (typically "M-D-Y_H-M_note" where note is some high level tag like "initial-shooter-test" or something like that)
    individual logs
    note file describing what is being tested (if applicable) for future reference
